## Setup

1. Install [uv](https://docs.astral.sh/uv/getting-started/installation/).
2. Clone the repo, then in the project folder run:
   ```
   uv sync
   ```
   This creates a `.venv` with the exact package versions we use.
3. Open the project folder in VS Code and pick the `.venv` kernel (top right of a notebook).
